# Задание для Человека C — презентация, видео, контроль сдачи

Код писать не нужно, нейросеть не обязательна. Нужны Google Slides (или Canva), запись экрана
и внимательность. Срок: черновик презентации — **31 октября к 14:00**, голос для видео — к **19:00**.

## Что за проект (своими словами для слайдов)

Хакатон Decentrathon 6.0, кейс **Soup Kernel Challenge**. Есть программа Soup, которая дообучает
языковую модель Qwen2.5-1.5B на видеокарте T4. Задача — сделать так, чтобы то же самое обучение
шло **быстрее** и занимало **меньше видеопамяти**, а результат остался **тем же самым**.
Для этого мы написали свои программы для видеокарты (кернелы) на языке Triton.

Главная находка команды: большая часть памяти уходила на хранение промежуточных чисел в «толстом»
формате fp32 (4 байта), хотя сами числа были посчитаны в «тонком» fp16 (2 байта). Мы храним их в fp16 —
это ничего не теряет, но экономит гигабайты. А огромную таблицу «логитов» (вероятности 152 000 слов
для каждого токена, ~1,2 ГБ) мы вообще не создаём целиком — считаем по кускам.

## 2. Голос для видео (видео соберёт капитан с Claude)

Видео делать не нужно — только записать **голос** по тексту, который пришлёт капитан
(2–3 минуты). Записать на телефон (диктофон) или на компьютер, в тихой комнате, спокойно и не спеша.
Можно частями: один файл на слайд, в имени — номер слайда (`slide1.m4a`, `slide2.m4a`, …),
или один файл и рядом время: «0:00 — слайд 1, 0:25 — слайд 2, …». Файлы — капитану.
Claude соберёт из слайдов и голоса готовое видео.

Для этого презентацию нужно отдать ещё и **картинками**: в Google Slides — Файл → Скачать →
PDF (капитан сам нарежет), либо каждый слайд как PNG.

**Commit changes** → выбрать «Create a new branch» → **Propose changes** → **Create pull request**.
